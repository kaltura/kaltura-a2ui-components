## 0.7.0: built for A2UI 1.0

First release for outside use. It renders A2UI 1.0 and needs `@a2ui/react` and `@a2ui/web_core` 0.15. The script-tag bundle has no peers.

### What you get

| Area | Detail |
|---|---|
| Wire | A2UI 1.0 messages: `"version": "1.0"`, `{ "@path": "..." }` bindings, `@call` functions |
| Catalog | `https://kaltura.github.io/a2ui/v3/catalog.json`: 18 basic and 12 Kaltura components, with `common_types.json` beside it |
| Capabilities | `getRendererCapabilities({ versions: ['1.0'] })`, sent as `a2uiRendererCapabilities` |
| Errors | `toClientError` returns the 1.0 renderer-to-agent message. `processMessagesWithErrors` keeps good messages when one is bad |
| Accessibility | All 12 widgets honour the component's `accessibility` property. The basic TextField label is tied to its input |
| Theming | Widgets follow `data-theme`, then an `a2ui-dark` or `a2ui-light` class, then the system setting ([theming](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.7.0/docs/theming.md)) |
| Safety | `openUrl` and `copyToClipboard` are renderer-only. The basic Video `posterUrl` gets the same URL check as `url` |
| Demo | `npm run demo` plays 12 recorded conversations that cover every Kaltura component ([examples](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.7.0/examples/README.md)) |

### Known

- The catalog cannot say "exactly one of `entryId` and `playlistId`" on the Player. The Player refuses a mix at run time.
- Zod stays on 3.x, with the dated exception from 0.6.1.

### Install

```sh
npm i github:kaltura/kaltura-a2ui-components#v0.7.0 @a2ui/react@^0.15.0 @a2ui/web_core@^0.15.0
```

Script-tag pages use `@v0.7.0` and the `integrity` value from the Release assets.
