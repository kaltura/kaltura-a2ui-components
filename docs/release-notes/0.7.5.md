## 0.7.5: Genie runs on Unisphere embeds, and editors are latest-wins

Genie now uses the Unisphere embeds API. Content Lab, Agents widget and VOD Avatar close the open editor when a new one starts. The catalog changed.

### Changed

- **Genie uses the Unisphere embeds API.** Each Genie gets its own workspace, so Genie shares a page with any editor, with the Avatar and with another Genie. Check Genie on your page after you update.
  - `uiconfId` is now optional and ignored. Old messages that send it keep working.
  - `language` is accepted and ignored. The embeds API has no language setting.
  - `categoryId` becomes the category context of the chat.
  - The error text is fixed: `Failed to load Kaltura Genie: Genie could not start`.
- **Editors are latest-wins.** Content Lab, Agents widget and VOD Avatar open over the page, so one is open at a time. A new one closes the open one. Before, a second one failed with "workspace already reserved", or showed an empty shell.
- **Drawer widgets have no empty box.** Their container has no border, margin or 500 px minimum height. Hosts that style `.kaltura-kaltura-agents-container`, `.kaltura-kaltura-content-lab-container` or `.kaltura-kaltura-vod-avatar-container` should check the page. The class names are unchanged. The new `kaltura-unisphere-overlay` class marks these containers.
- **Embeds env.** The Avatar and Genie send the environment of the Unisphere host, so they also work on a QA stack such as `nvq2`.
- **`reportType` description.** The Analytics catalog text says that `entryId` wins over `reportType`, so agents stop asking for an entry-level geo view.

### Limits

- The editors share one workspace. The first editor on a page fixes the account and region for the next ones. Reload the page to switch.
