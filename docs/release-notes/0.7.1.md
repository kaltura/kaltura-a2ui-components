## 0.7.1: attest every release file

Same code and catalog as 0.7.0. The release now attests `common_types.json` too, so all files the catalog needs carry a build attestation.

### Changed

- `common_types.json`, the file beside `kaltura_catalog.json`, is part of the attested subjects. In 0.7.0 only its hash in the attested `SHA256SUMS` covered it.
- The live demo is built and published from `main` ([demo](https://kaltura.github.io/kaltura-a2ui-components/)).

### Install

```sh
npm i github:kaltura/kaltura-a2ui-components#v0.7.1 @a2ui/react@^0.15.0 @a2ui/web_core@^0.15.0
```

Script-tag pages use `@v0.7.1` and the `integrity` value from the Release assets.
