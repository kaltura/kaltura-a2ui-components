## 0.7.2: found by a real-model end-to-end run

Gemini (`gemini-3.5-flash`) wrote 8 decks through the [ADK sample](https://github.com/kaltura/a2ui/tree/main/samples/adk-agent). All 8 passed the A2UI SDK check, then played in the demo on 3 browsers. Axe found three accessibility bugs. They are fixed here. The catalog is unchanged.

### Fixed

| Area | Fix |
|---|---|
| Flashcards | The counter and the Start and Next button were white on the page, 1.1:1 in the light theme. They now follow the page text tokens |
| Basic Slider | The range input had no accessible name. It is now named by the Slider label |
| Basic TextField, CheckBox, Slider | The default error red is 3.54:1 on light and 4.35:1 on dark, and the Slider spills out of its card. Set `--a2ui-textfield-color-error`, `--a2ui-checkbox-color-error`, `--a2ui-slider-color-error` and `--a2ui-slider-margin` ([theming](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.7.2/docs/theming.md)). The demo sets them |

### Tests

The Study kit run now opens the flashcards tab and checks axe in both themes. Before, the deck sat in a closed tab and no check saw it.

### Install

```sh
npm i github:kaltura/kaltura-a2ui-components#v0.7.2 @a2ui/react@^0.15.0 @a2ui/web_core@^0.15.0
```

Script-tag pages use `@v0.7.2` and the `integrity` value from the Release assets.
