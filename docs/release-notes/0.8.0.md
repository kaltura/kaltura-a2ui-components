## 0.8.0: the recorder is the new Kaltura Express Recorder

`KalturaRecorder` now frames the new Kaltura Express Recorder (Unisphere) instead of loading the old script into your page. The KS goes to the frame by `postMessage`, so page scripts cannot read it. Your CSP and `Permissions-Policy` need a change before you update.

### Breaking for hosts

| What | Do this |
|---|---|
| CSP `frame-src` | Allow `https://unisphere.<region>.ovp.kaltura.com/v1/`. The old recorder `script-src` entries are no longer needed ([CSP](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.8.0/docs/host-integration.md#content-security-policy)) |
| `Permissions-Policy` | Delegate `camera`, `microphone`, `display-capture` and `fullscreen` to the Unisphere origin. Without it the recorder opens but cannot capture ([Recorder permissions](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.8.0/docs/host-integration.md#recorder-permissions)) |
| `hosts.recorder` | Removed from the region table. Read the Unisphere host from the region instead |
| Custom environments | The recorder takes built-in region codes only. A custom environment fails with `Failed to load recorder: region has no Unisphere host` |

### Changed

- **Recorder** loads from `loader.html` in a frame with `allow="camera; microphone; display-capture; fullscreen"` and `sandbox="allow-scripts allow-same-origin allow-downloads"`.
- **`recorder-upload-ended`** now comes from the recorder's `uploadComplete`. `entryId` is the main entry. `entries` is added when a take has more than one (camera and screen). Ids are checked and nothing else from the frame is passed on. The agent action context gets `entryId` and `entryIds`.
- **Load failure**: no `recorderInit` in 15 seconds gives `load-failed` with the text `Recorder could not start`.
- The recorder KS still needs `editadmintags:*`. Checked live: without it the recorder shows "Upload failed" and sends no event.

### Added

- `orientation` (`landscape` or `portrait`) fixes the capture orientation.
- `prompterText` opens a script in the recorder's teleprompter. The user can edit it.
- The catalog changed (new props). The catalog id stays `v3`.

### Removed

- The Express Recorder script loader and its pinned path.
- `hosts.recorder`.

### Known limits

- English only and light theme. The frame has no setting for either.
- No `sgp2` region.
- The recorder sends no error, progress or cancel message. You get `recorder-upload-ended` and the load error only.
- The runtime inside the frame is chosen by Kaltura. The loader page is pinned to a version, the code behind it is not. We accept both payload shapes of `uploadComplete` seen so far.
