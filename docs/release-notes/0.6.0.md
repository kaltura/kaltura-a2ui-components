## 0.6.0: A2UI 0.14 peers

This release moves the peer dependencies to A2UI 0.14. **ESM installs must update their peers.** The script-tag bundle (`kaltura-wc.js`) has no peers and needs no change.

### What changed

| Area | Change |
|---|---|
| Peers | `@a2ui/react` and `@a2ui/web_core` `^0.14.0`. 0.13 stops the install with `ERESOLVE` |
| Catalog | Same components and props. The JSON has formatting changes only |
| Node imports | Unchanged. Import `@kaltura/a2ui-react` before `@a2ui/react`. `@a2ui/react` 0.14.0 still needs the `HTMLElement` stub |
| `dompurify` override | Keep it. `@a2ui/markdown-it` 0.2.2 still pins 3.4.11 |

### Upgrade

```sh
npm i github:kaltura/kaltura-a2ui-components#v0.6.0 @a2ui/react@^0.14.0 @a2ui/web_core@^0.14.0
```

Remove any pin on `@a2ui/markdown-it@0.2.1`. CSS or tests that select basic component markup must use the new `a2ui-` prefixed class names. Steps and details: [migration-a2ui-0.14.md](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.6.0/docs/migration-a2ui-0.14.md).

### Tested

- 2735 unit tests, 522 browser tests on Chromium, Firefox and WebKit.
- 88 live tests on two Kaltura environments, in Chromium, Firefox and WebKit: Player, Flashcards, Captions editor, Recorder, Analytics, Media Manager, Genie, Content Lab, Agents Widget, VOD Avatar and Avatar. The Recorder test runs in Chromium only, because it needs its fake media devices.
- A consumer check with the packed package and the new peers, in Node and on a bare page.
