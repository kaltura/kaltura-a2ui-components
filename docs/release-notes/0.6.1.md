## 0.6.1: security fixes in the bundle

Script-tag users should update: the `markdown-it` fix and the prop size cap are inside `kaltura-wc.js`. ESM installs get the prop size cap. Public API and peers are unchanged.

### What changed

| Area | Change |
|---|---|
| `markdown-it` 14.3.3 | Fixes GHSA-gfr2-rv44-r23c (high, slow parsing of link references) and GHSA-vfgh-jcmw-g37q (low). It is bundled in `kaltura-wc.js` |
| Prop size cap | A prop with an array or record over 10,000 items is refused by name before parsing. Zod 3 spends memory on every bad item first (GHSA-mrhx-c7xc-m3w5, fixed only in Zod 4). Real props are far smaller |
| Bundled `react` and `react-dom` | 19.3.1 |
| Dev dependencies | `undici`, `fast-uri` and `minimatch` fixes. These are not shipped |

### Known

Zod stays on 3.x because `@a2ui/react` and `@a2ui/web_core` need `^3.25.76`. The advisory above is an accepted, dated exception until 2026-12-31 (see [ADR 0003](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.6.1/docs/adr/0003-peer-dependencies.md)).

### Upgrade

```sh
npm i github:kaltura/kaltura-a2ui-components#v0.6.1
```

Script-tag pages change `@v0.6.0` to `@v0.6.1` and the `integrity` value.
