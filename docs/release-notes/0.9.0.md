## 0.9.0: A2UI 0.16 and catalog v4

The renderer moves to `@a2ui/react` and `@a2ui/web_core` 0.16.1. The catalog id is now `v4`. Agents and hosts both need a change before you update.

### Breaking for hosts

| What | Do this |
|---|---|
| Peers | `@a2ui/react ^0.16.1` and `@a2ui/web_core ^0.16.1`. A host on 0.15 gets an install error that names the peer |
| Catalog id | `https://kaltura.github.io/a2ui/v4/catalog.json` replaces `v3` in `KALTURA_CATALOG_ID`. Send the new id in `createSurface.catalogId` and in your agent prompt. `v3` stays online and frozen ([ADR 0012](https://github.com/kaltura/kaltura-a2ui-components/blob/v0.9.0/docs/adr/0012-catalog-versioning.md)) |
| Agents still on `v3` | Register `buildKalturaCatalog('https://kaltura.github.io/a2ui/v3/catalog.json')`. 0.16 still reads the bare `accessibility` key, so `v3` streams render. The renderer does not serve `v3` by default. A later `web_core` release may stop reading the bare key (test T8 pins it) |
| Component keys | `@catalogId`, `@accessibility`, `@metadata` and `@checks` replace `catalogId`, `accessibility`, `metadata` and `checks`. New agents send the `@` keys |
| `Tabs` | `@a2ui/react` 0.16 renders `tablist`, `tab` and `tabpanel` roles. Tests that click a tab as a `button` must use the `tab` role |
| `openUrl` | `A2uiExpressionError` ("Invalid URI") is thrown by the function schema, before our handler, for an empty value, a tab or newline in the scheme, or text that is not a URL. Other unsafe schemes are still ignored with a warning |
| Basic `TextField` | `value` is now required next to `label` |

### Changed

- `@a2ui/markdown-it` 0.2.4 depends on `dompurify ^3.4.17`. The `dompurify` override is no longer needed. Remove it from your `package.json` if you added it.
- The regex `pattern` description in the catalog follows the A2UI regex dialect.
- `@a2ui/react` now imports in plain Node (upstream fix, a2ui-project/a2ui#3197). We still ship the SSR stub. It goes in a later release.

### Install

```sh
npm i github:kaltura/kaltura-a2ui-components#v0.9.0 @a2ui/react@^0.16.1 @a2ui/web_core@^0.16.1
```
