## 0.7.6: Content Lab loads again, and Genie `language` works again

Kaltura rolled out Content Lab 1.45.2 on 2026-11-15. Its `ai-consent` runtime now rejects settings without `uiconfId`, so Content Lab showed "Failed to load Kaltura Content Lab" on every library version. This release sends it. Genie `language` was ignored in 0.7.5. The embeds loader accepts `ui.language`, so it works again.

### Changed

- **Content Lab** sends `uiconfId` to the `ai-consent` runtime. Update to get Content Lab back.
- **Genie `language`** sets the UI language again, for example `de`. Without it Genie stays in English. The 0.7.5 note that it is ignored was wrong.
- The Genie catalog text for `language` says so. The catalog changed.
