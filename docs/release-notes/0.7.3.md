## 0.7.3: the player label stays readable while the video plays

The Kaltura Player adds its own style for a class named `kaltura-player-container`. Our wrapper used the same class name. Once a video played, the Player's style gave our wrapper a black background, so the dark title text on a light page was 1.66:1. A live run against a real account and the Claude Haiku 5.5 demo found it. The catalog is unchanged.

### Fixed

| Area | Fix |
|---|---|
| Player | The wrapper class is now `kaltura-a2ui-player`, so the Player's styles no longer reach it. |

### Tests

The live suite has a new test (LIVE-22). It plays a real entry, then checks that the wrapper keeps its own background and that its text passes axe.
