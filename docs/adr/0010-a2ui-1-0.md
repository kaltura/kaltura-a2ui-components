# 0010. Build on A2UI 1.0

Status: accepted (2026-11-12)

Plan and status: [plan-a2ui-1.0-upgrade.md](../plan-a2ui-1.0-upgrade.md). What comes next: [roadmap.md](../roadmap.md).

## Context

- A2UI 1.0 wire: `version: "1.0"`, `{ "@path": ... }` bindings, `@call` function calls, `renderer_to_agent` errors, `a2uiRendererCapabilities`.
- `@a2ui/react` and `@a2ui/web_core` 0.15 render 1.0.
- 0.15.0 rejects the `@`-prefixed envelope keys that the spec names (`@accessibility`, `@checks`). Bare `accessibility` is accepted. The pin test `test/conformance/envelope-keys.test.ts` fails when a release changes this.
- Nobody outside the lab used earlier versions (decision of 2026-11-12). 0.7.0 is the first release we recommend, so there is no older protocol to support.

## Decision

- Protocol 1.0 only. Peers are `@a2ui/react ^0.15.0` and `@a2ui/web_core ^0.15.0`.
- Catalog id `https://kaltura.github.io/a2ui/v3/catalog.json` ([ADR 0006](0006-catalog-generation.md)).
- Ship on the 0.15.0 wire (bare `accessibility`). Adopt the `@` envelope keys in a later minor, after upstream releases them.
- The 12 widgets honour `accessibility` (`label`, `description`, `live`, `hidden`) through the shared wrapper in `src/adapters/react/agent-action.tsx`.
- Widgets follow the host theme: `data-theme`, then an `a2ui-dark` or `a2ui-light` class, then `prefers-color-scheme` ([theming](../theming.md)).
- `openUrl` and `copyToClipboard` are renderer-only functions.
- Examples are files in `examples/a2ui/`. A test loads and renders each one, and the live demo plays them.
- No npm package. Distribution stays jsDelivr from git tags ([ADR 0004](0004-git-tag-distribution.md)).
- No compatibility layers for older versions. Only the latest minor gets fixes.

## Consequences

- Messages in any other protocol version fail validation.
- When upstream releases the `@` envelope keys, the pin test fails and tells us to adopt them.
