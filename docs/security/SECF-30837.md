Internal hardening review. This table links each finding ID to its fix item, test and CI job. It holds IDs only. Details go to a private advisory, not this repo.

Fix item numbers refer to the remediation items listed in this table.

**Status values**

| Status | Meaning |
|---|---|
| fixed | Fix is in the branch and its tests run in the default suite and pass. |
| partial | Some fix items are done. The rest is named in the row's Test column. |
| blocked | Waits on a third party. The test is skipped with the reason in its title. |
| open | Not fixed. The test is a pending probe, or none exists yet. |
| accepted | Known and accepted. Documented only. |

**Test paths** are relative to the repo root. `e2e/` specs run in Playwright. Everything else runs in vitest (`npm test`). Files listed in `test/pending.ts` are skipped by `npm test`. Run them with `RUN_PENDING=1 npm test`. E2E cases titled `[pending ...]` are skipped by `npm run e2e`. Run them with `E2E_PENDING=1`.

**CI job** names are the `name:` values in `.github/workflows/`. `e2e` runs the job once per browser: `e2e (chromium)`, `e2e (firefox)`, `e2e (webkit)`.
